## 活动入口和自定义购买，实际差别在哪？

差别在配置自由度和价格：活动页是固定配置的特价机，自定义购买是自由组合按需计价。

活动机的配置是固定的，只能选地域和镜像。记住一点：镜像买完可以免费改，地域买完不能改。活动页下单时地域选错，没有补救办法，只能重新买一台。

自定义购买反过来，配置随便选，代价是价格随组合上涨。同样标称 2核4G，加上带宽、系统盘、镜像的差异，最终金额可能比活动机高不少。好处是能精确匹配需求，比如要 5Mbps 带宽、要 100G 系统盘、要用 GPU 实例，只有自定义购买能满足。

两条路径有一个共同点：买完发现配置不合适，都能在后台用「调整实例配置」升级或降配，支付差价就行。预算卡得紧的话，先买活动机、后续不够用再升配，是可行的策略。

## 从入口到下单：完整流程和每一步的选法

从入口点进去之后，购买流程按顺序是：计费模式、地域、可用区、实例规格、CPU 内存、镜像、存储、网络与带宽、安全组、登录方式。前面几步最关键，后面的选项买完大多能改。

1. **计费模式**：包年包月适合长期稳定使用，先付费，有折扣；按量计费适合短期或流量波动大的业务，用多少算多少；竞价实例最高能到按量计费 80% 的折扣，但实例可能被系统自动释放，只适合无状态、可中断的任务。活动页的机器都是包年包月。
2. **地域**：按用户位置就近选，用户在华北选北京，在华东选上海。不同地域之间内网不互通，地域买完不能改。
3. **可用区**：同一地域内电力、网络独立的区域。只买一台随机即可；多台部署时分散到不同可用区，一个区出故障不影响另一个区。
4. **实例规格**：建站选标准型；内存密集型业务选内存型，计算密集型选计算型，需要显卡选 GPU 型。
5. **CPU 内存**：个人博客、开发者网站 1核2G 起步；企业应用建议 2核4G 起。买小了可以后升级，支付差价。
6. **镜像**：公共镜像里有 TencentOS Server、OpenCloudOS Server、CentOS Stream、Windows Server 等。Linux 建站选 TencentOS 或 OpenCloudOS 都行，装完也可以换。
7. **存储**：系统盘必选，数据盘可以先不买，后续挂载。系统盘介质分高性能云硬盘、SSD 云硬盘、通用型 SSD 云硬盘，介质类型购买后不支持更换，这一步要想好。
8. **网络与带宽**：需要公网 IP 就勾选，勾选后带宽至少 1Mbps。按带宽计费是买固定带宽、先付费；按流量计费是用多少算多少、后付费。小站先买 1Mbps 按带宽。
9. **安全组**：相当于虚拟防火墙。建站至少放通 80、443 和 SSH 端口，选「放通常用端口」最省事，规则后续可以改。
10. **登录方式**：Linux 系统建议 SSH 密钥登录，创建时生成密钥对并保存到本地，比密码安全；Windows 选密码即可。

页面底部默认勾选安全加固、云监控和自动化助手，三项都免费，保持勾选就行。安全加固会自动安装 DDoS 防护和主机安全基础版组件，云监控提供资源监控和实时告警，自动化助手可以免密码、免 SSH 登录批量管理实例。

## 几个买完就改不了的细节

有几项配置下单后无法更改，或者容易被忽略但直接影响使用：

- **地域**：不能改。活动机尤其要注意，下单前确认用户主要在哪。
- **系统盘介质**：不能换。高性能云硬盘、SSD 云硬盘、通用型 SSD 云硬盘，买之前定下来。
- **定期快照**：中国境内每个地域有 80GB 免费额度，超出部分收费。购买时可以不勾选，后续在控制台手动设置。
- **带宽**：1Mbps 是多数展示机型的起步配置，上线后流量涨了可以升带宽，不用一步到位买大带宽。

反过来，可以改的有镜像、实例配置（升降配）、数据盘（后挂载）、安全组规则。所以下单时真正需要慎重的只有地域和系统盘介质。
